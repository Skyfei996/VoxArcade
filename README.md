# VoxArcade · 声控街机

一款通过流程编排操作的方块游戏。选形后立即显示出生形状，动作加入草稿；点击“落地并提交”自动运行整份流程，也可用“结束并运行流程”在当前位置结束。

## 运行原型

在项目目录执行 `node prototype/serve.mjs`，访问 `http://localhost:4173/`。手机与电脑连接同一局域网后，用电脑 WLAN IPv4 地址替换 localhost。

Windows 已配置当前用户登录后自动在后台启动，入口为 `prototype/start-preview.ps1`，启动项为 Startup 目录中的 `VoxArcade Preview.lnk`。也可右键该脚本并使用 PowerShell 运行，重复启动会复用已有服务。

后续游戏修改均更新本项目 `prototype/` 源文件，固定在 `http://localhost:4173/` 验收。HTML、CSS 和游戏脚本保存后刷新即可；修改 `serve.mjs` 后需重启服务。此服务直接读取源文件，无需构建。

## GitHub Pages 与 Codex Cloud

GitHub 仓库：<https://github.com/Skyfei996/VoxArcade>。按钮版游戏已发布至 <https://skyfei996.github.io/VoxArcade/>。`.github/workflows/pages.yml` 在 `main` 的游戏文件更新后自动执行，也保留手动运行入口。完成检查后自动提交、推送并合并游戏改动，部署成功且核验线上页面后交付。Pages 的 Source 为 GitHub Actions，普通游戏同步已获长期授权。

发布包只包含游戏入口、PC/手机视图、规则、音效和旋转演示。语音验证页、模型、测试脚本、预览服务和评审截图不会成为公开站点内容。大型语音模型和评审截图也由 `.gitignore` 排除在首版仓库之外，本地文件保留。

本机 GitHub 认证已通过 Git Credential Manager 的设备授权完成，不把 token 放进聊天、文件或命令参数。Codex Cloud 尚需在 Work in → Cloud 中另行连接该 GitHub 仓库并创建环境；本机 Git 凭据不会自动同步到云端。云端环境使用本项目 `AGENTS.md`，运行 `node --test prototype/tests/engine.test.mjs prototype/tests/device-audio.test.mjs` 验证改动；普通游戏改动完成检查后自动合并并同步 Pages。

入口自动识别设备，加载独立的 PC 或手机页面。PC 窄窗口仍保持 PC 视图；手机横屏沿用手机版。电脑浏览器按 F12 切换手机设备后刷新页面可查看手机版，也可访问 `http://localhost:4173/?view=mobile` 强制预览。两端共用游戏规则，分别提供布局及视图交互：PC 单列关卡/后续方块栏与大棋盘，手机首屏棋盘和操作区、可展开编辑的流程抽屉。暂存入口已隐藏。

默认打开第一关。共有二十五关，分为简单、中等、困难、特困难，分别采用自由排序和固定顺序。

## 当前规则

- 选形显示初始形状和直接下落影子；工具栏眼睛图标可打开旋转预览，顺逆转按钮会临时转动棋盘上的方块，离开预览区后还原。草稿动作不提前执行，也不预演完整流程结果。PC 棋盘四边标出行列坐标。
- 选择格数并添加一次操作后，格数重置为 1。
- 一轮流程只操作一个方块；运行结束自动清空流程。
- 左右移动途中受阻则整步无效；接地时横移受阻，或下移实际受阻，才终止流程。刚好接地可横移，脱离障碍后可继续下移。
- 流程结束固定当前位置，悬空也保留为障碍，然后换下一块。
- 自由排序形状旁 ×N 表示剩余未用数量，包含当前待提交方块；固定顺序库存逐块排列。必须用完所有给定方块且棋盘为空才通关。
- 无尽支持手动和可调速度自动下落，编排时冻结，运行时才自动下降。
- 真实语音尚未接入；采用基础旋转与计分。公开站点只发布按钮版游戏，不包含语音验证页及模型。
- 落地连续下降，消行闪烁后上方行下移；当前步骤在方块旁显示。设置提供独立背景音乐/游戏音效开关，音效包含过关和失败。
- 设置 → 旋转演示：当前页面内弹窗，七种形状的空场、贴墙、障碍和受阻示例，支持顺逆转、逐步观看与重播。
- 网格按显示尺寸和屏幕像素密度绘制，音频增益为上一版的 2 倍；左右/下移、顺逆转、受阻、实际接地及悬空固定分别反馈。声音在对应事件发生时播放，不在渲染时重播。

## 2026-10-24 更新

- 四种玩法：解谜闯关、无尽编排、常规模式、舒航模式。常规模式没有流程，点击立即操作，方块持续自动下落；暂停后需手动继续。
- 所有模式只按消行计分：一行 100、两行 300、三行 600、四行 1000。移动和落地无附加分，等级不乘积分。
- 常规模式速度等级 1–9：每秒 0.8、1.2、1.8、2.6、3.6、5、6.5、8、10 格。可选起始等级；勾选积分升级后每 1000 分提升一级，最高九级，关闭后保持手动等级。
- 单块撤回恢复上一块执行前的棋盘、库存、分数、动作数与当前方块；只能撤回一次，重玩并提交后可再次撤回。运行及动画期间禁用，常规撤回后暂停。
- 每次打开页面显示一次可跳过的分步引导，切换模式不重复显示，帮助入口可重看；手机帮助入口在设置内。旋转预览与重置使用不同图标。
- 默认第一关，保留原八关编号并新增七关；选关列表按难度分组，编号不代表难度先后。

## 舒航模式

简单每层 3 块，中等 4 块，困难 5 块。逐个点击候选，点击顺序即出场顺序；选中后只安排左右移动和旋转，不加动作则按初始方向直接落地。点击已选块可继续编辑；在整层方案中用 ↑ 调整出场顺序，× 删除动作或取消安排。

全部候选都选完后点击“整批提交”。规划时棋盘冻结，选中候选后显示该块的出生位置和初始方向，便于计算移动格数；添加动作不会改变这张出生示意，也不显示旋转结果或落点影子。提交后整层锁定，每块依次执行动作、自动落地、消行。整批未溢出就进入下一层并保留棋盘、积分；失败显示到达与通过层数。切换难度重新开局。手机点击“整层方案”查看和编辑逐块步骤。

本模式没有下移、单块落地、暂存或单块撤回；执行可暂停、继续，但不能修改方案。积分沿用 100/300/600/1000 消行规则。

## 2026-10-24 棋盘优先布局

分数、旋转预览、撤回、重开、移动格数、难度/等级及方块列表整合到棋盘侧边。常规/无尽列表最上面显示当前方块，后续方块接在下面；解谜和舒航保留可选择的库存/候选列表。手机隐藏品牌行并压缩顶部模式栏，旋转预览和撤回保留完整文字与至少 44px 的触摸区域。

主界面不再显示整行积分规则、手动下落字样或底部常驻说明。操作失败使用临时提示；设置和帮助仍可查看详细规则。每次打开页面只自动引导一次，本次使用中切换模式不会再次弹出，帮助入口可主动重看当前模式。

## 2026-10-27 关卡递进与快速下移

共 25 关，按简单 4 关 → 中等 11 关 → 困难 5 关 → 特困难 5 关连续推进。新增中等五关、困难三关、特困难两关；原关卡 ID 和内容保留，旧通关记录自动按 ID 迁移到新编号。

长按落地按钮仍只切换操作。只落地在执行时计算可下降距离，执行相同格数的快速下移；编排时仍只加入步骤。落地后可以在同一流程继续横移，正常流程结束照常固定；常规模式继续原重力计时和正常触底锁定，可以立即横移，无额外提交按钮。舒航仍按整批方案执行。
