# 方块交互、动画与声音改进方案

日期：2026-10-21。状态：已实现并通过验证；包含新增的旋转演示及过关、失败音效。详细结果见 [PROTOTYPE_REVIEW.md](PROTOTYPE_REVIEW.md)。音频已验证实际信号输出，尚无人耳听感评审。

## 范围与规则调整

- 自由排序关卡：点击形状后，立即在棋盘出生位置显示该形状；切换选择同步替换显示。库存仍在提交后扣减。仅显示初始形状，不预演草稿中的移动、旋转、落点或碰撞结果。
- 点击“落地并提交”：把该指令追加到草稿末尾，并立即运行整个草稿；保留“运行流程”，供不含落地指令、需悬空固定的流程使用。无可用形状、正在运行或本局已结束时，提示原因，不创建无效流程。
- 旋转算法、碰撞试移顺序不改动；按最新要求增加独立示例演示，不在实际棋盘上预测草稿旋转结果。
- 已同步 AGENTS.md、COMMAND_SET.md 和相关验收约定。继续复用 localhost:4173，不部署、不修改系统或安装全局依赖。

## 交互方案

1. 棋盘：提高每格边界与背景的对比度，在手机和桌面均能分辨格数，保持方块与底格层次。
2. 落地：显示约 200–300 毫秒的快速下落，从当前坐标连续移动到实际合法落点。动画期间不接受重复提交或推进下一步，不提前显示新方块和结果弹窗。
3. 消行：满行闪烁三次，约 400–500 毫秒，再移除；随后上方行下移、结算并换块。无消行时直接进入正常收尾。动画与逻辑结算保持同一顺序，防止重复计分、扣库存或生成方块。
4. 当前步骤：在移动方块旁显示“第 N 步 · 左移 2 格”等正在执行的文字；横向空间不足时放在上方或下方并限制在棋盘范围内。右侧流程列表保留。受阻时显示该步实际结果，运行结束后短暂保留最后一步，再隐藏。
5. 暂停与切换：暂停同时冻结流程、下落和消行动画；继续不重放步骤。重开、切换模式或关卡后，不允许旧动画回调操作新局。最后一步动画结束后才清空草稿、显示结果。

## 新增任务：旋转演示 HTML

- 设置内增加“旋转演示”入口，与声音设置同级。点击后关闭设置对话框，在当前游戏页面打开演示对话框；不打开新标签页，不跳转游戏页面。关闭演示返回设置，保留棋盘、草稿和暂停状态，不自动继续运行。
- 示例文件拟放在现有 prototype/ 下，使用 rotation-demo.html 和 rotation-demo.mjs；HTML 嵌入当前页面的对话框。实施前将文件用途补入 AGENTS.md 的目录约定，不新增目录。
- 支持选择 I、O、T、J、L、S、Z 全部七种形状，提供顺时针、逆时针、逐步播放和重播。显示清晰格线、行列编号、矩阵边框及旋转中心；原位置用轮廓表示，实际结果用实色表示，避免仅靠文字想象。
- 每种形状分别提供空场、靠左墙、靠右墙、已有方块障碍及旋转失败场景。展示旋转前、原位旋转候选、按 0/-1/+1/-2/+2 顺序实际检查过的位置和最终结果；标明碰撞格及实际横移几格，成功后停止试移，不演示引擎不会执行的后续候选。
- 场景的预设起点须本身合法。可用四种朝向构造贴墙示例；O 的占格在旋转后保持不变，合法起点下不会因旋转新产生碰撞，明确展示这一点，不人为制造挪位或失败。其他形状某个朝向原位可旋转时，也如实显示无需挪位。
- 示例调用实际引擎的旋转与碰撞逻辑，在独立示例棋盘上执行；动画中的中间候选从同一规则取得，避免演示和游戏存在两套算法。示例不读取或改写玩家当前局面。
- 验收：七种形状、两种旋转方向和每个预设场景的最终矩阵及位置均与实际引擎一致；额外确认 O 不变、I 顺逆转占列差异、左右墙补偿、障碍补偿及全部候选失败。手机对话框不横向溢出，关闭后回到原设置状态。

## 声音方案

- 使用浏览器合成简短循环背景音乐及移动、落地、消行音效，无需下载或新增外部音频资源。
- 设置中提供两个独立开关：“背景音乐”和“游戏音效”，两种游戏模式共用；游戏音效包含移动、旋转、落地、消行、过关和失败，保存到本地，下次打开沿用。
- 首次默认背景音乐关闭、音效开启；首次用户交互后才启动音频。
- 成功移动、旋转及落地时播放对应短音；编排动作不提前播放执行音效。消除 1、2、3、4 行时音量递增，在固定最大音量内控制峰值。
- 过关播放简短上扬旋律，失败播放明显不同的低沉收尾音。两者遵守“游戏音效”开关；每局最终结算只播放一次，消行动画结束后再播放结果音，暂停、关闭演示、普通流程结束及重复渲染均不触发结果音。
- 暂停、切到后台或本局结束时停止背景音乐；关闭音效立即停止正在播放的效果。恢复时遵守各自开关，不叠加多个音乐循环。

## 实施顺序与验收

1. 更新规则并实现选形即显示、落地按钮自动运行。验证：自由排序可替换选择、不提前扣库存；点击一次落地即可完成已有草稿；固定顺序及无尽当前形状正常。
2. 实现落地、消行和步骤文字。验证：抽查动画中间帧，确认有真实下落路径、三次闪烁、正确文字与行下移顺序；暂停恢复及新局隔离正常。
3. 加入合成声音与独立开关。验证：开关组合、刷新记忆、暂停/后台静音、消行数对应音量递增、过关和失败只播放一次且音效关闭时静音；完成实际听感检查后记录结果。
4. 制作旋转演示 HTML 并接入设置对话框入口。验证：七种形状的无障碍、有障碍结果与实际引擎一致，对话框内完成播放和重播，关闭后局面与草稿保持原样。
5. 运行项目语法检查、引擎测试和浏览器验证。更新旧的“编排期间棋盘像素绝不变化”断言，使其允许初始选形显示，但仍禁止执行草稿动作或落点预演；测试落地自动启动后不再额外点击运行。
6. 通过全部八关解法回归，并实际检查无尽手动/自动下落、窄屏布局、步骤文字不出界和重复点击不重复结算；评审截图写入既有 prototype/review/，更新验证记录。

## 当前旋转规则核对

- 源码：prototype/engine.mjs 中 rotate 与 dispatch 的 ROTATE_CW / ROTATE_CCW 分支。
- I 使用 4×4 矩阵，O 使用 2×2，其余形状使用 3×3；空白格参与旋转。旋转中心是矩阵中心，初始候选保持矩阵左上角的棋盘坐标不变。
- 顺时针将局部坐标 (x,y) 变为 (N-1-y,x)，逆时针变为 (y,N-1-x)。棋盘横轴向右、纵轴向下。
- 旋转候选碰撞时，按水平偏移 0、-1、+1、-2、+2 顺序寻找合法位置；不向上或向下试移。都不合法则保持原形和位置，跳过该步。
- 初始 T 顺时针后从 `.T./TTT/...` 变为 `.T./.TT/.T.`；初始横向 I 顺时针后处于 4×4 矩阵从左数第三列，逆时针后处于第二列；O 占格不变。
- 已通过实际引擎调用核对 T、I、O 顺时针占格；现有引擎测试 24/24 通过。这是修改前的基线，不代表新功能已经完成。
