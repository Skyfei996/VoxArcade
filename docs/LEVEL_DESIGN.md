# 十五个关卡与参考解法

日期：2026-10-20。本轮增加进阶关，所有关卡必须用完给定方块且整个棋盘为空才通过。

## 库存与顺序

自由排序关卡按形状展示 ×N 剩余数量，玩家每轮选择一种形状。固定顺序关卡由预制队列生成当前块，并显示待用队列，不能选择其他形状。实例 ID 不向玩家展示。

数量包含当前尚未提交的方块；只编排不扣库存。重复形状有多个内部实例，不能重复消耗同一实例。中途空盘但有剩余方块时继续游戏。

| P007 | 既定的旅程 | 空盘 | 固定 I → O → Z → T → T → J → S → L |

P006 同时要求选序、旋转和位置安排；P007 保留相同形状总数，改为既定顺序，玩家必须适应给出的队列；P008 以已有八格为约束，从部分布局继续完成组合。

## 可执行参考解

真实引擎参考流程保存在 [level-solutions.mjs](../prototype/tests/level-solutions.mjs)，仅供验证，不显示到游戏 UI。

P006 的一种解：I 左二；O 右三；Z 右一；T 左二；第二个 T 顺转两次右二；J 顺转两次右三；S 保持；L 顺转两次左二。每轮选对应形状并以落地提交结束。

P007 使用同一朝向与位移序列，由固定队列提供形状。P008 使用上述解的后六块，从 Z 开始，适配预制底部八格。

作者搜索程序 [author-levels.mjs](../prototype/tests/author-levels.mjs) 曾使用真实流程执行器找到合法解，不进入网页或运行前校验。它在 1064 个搜索状态后找到 P006 解法；测试逐轮重放全部八关，验证合法路径、全部使用与最终空盘。

作者解不是唯一答案。所有合法解同样通过；UI 不做最优解或唯一解判断，也不提前展示可解性。

## 悬空规则与验证

流程没有落地步骤时，在执行末尾固定当前位置。悬空格成为后续碰撞障碍，只有满行消除引起的行移动会改变它们的位置。选择一块后直接结束流程也会把它留在出生处，可能阻挡后续出生，这是规划失误的有效结果。

格数守恒只是必要条件，不能替代真实重放。当前十五关均通过从实际出生坐标、矩阵旋转和逐格下落的流程重放，并检验未用完不提前通关。首批五关的旧落地模拟已由真实运行器测试替代。

以下仅供作者和测试使用，游戏目标文案不直接给出操作答案。棋盘仍为 6×8，列出底部初始行：

| ID | 初始行（从上往下） | 参考解每轮消行数 | 设计重点 |
| --- | --- | --- | --- |
| P009 | `...... / ..####` | 1、1 | O 左二，再 I 右一；可看到两块之间的衔接 |
| P010 | `#..... / ##.#..` | 0、2 | T 半转先落，再 O 右二补齐；固定顺序降低入门选择负担 |
| P011 | `...... / ...### / ...###` | 0、2、1 | L 顺转左二先搭形，S 顺转左一消两行，最后 I 右一 |
| P012 | `#..... / #..... / ###.#.` | 0、1、2 | T 顺转右一，L 逆转右三，O 左一；后两块落点要结合消行后的行移动 |
| P013 | `#..... / ##.... / ..#..# / ..#.##` | 0、1、1、2 | Z 原位、第二个 Z 顺转右二、J 顺转右一、O 左二；库存展示顺序不等于解题顺序 |

上述移动均从每块真实出生位置计算，每轮末尾落地提交。P011/P012/P013 的参考解均先做不消行的铺垫；测试同时确认按库存顺序原方向直接落地不能过关，倒放 P011/P013 参考出块顺序会失败。它们要求提前安排后续形状，且没有升级到空场七形拼图的复杂度。

去重检查比较初始布局、棋盘大小、库存与选序规则，并比较左右镜像（同时交换 J/L、S/Z）。固定队列与自由排序仍视为不同玩法，因此原 P006/P007 继续保留。作者筛选只枚举先旋转、横移、再直接落地的常用流程；统计不证明唯一解，所有合法引擎解法继续有效。
