# 游戏设计 · 流程方块

日期：2026-10-21。以老板确认的交互改进方案为准；继续使用流程编排，不预演草稿结果。

## 玩法核心

玩家观察真实棋盘，思考一块方块的动作，组合指令后运行。选形即显示初始形状；编排期间不执行移动和旋转，无落点影子、无碰撞结果预测。语音后续也只追加步骤。

一次运行负责一块。指令至少相隔 450 毫秒，当前动画完成后才执行下一步，结束后清空草稿。“落地并提交”自动运行整份草稿。玩家可以暂停，保留已执行步骤及动画进度继续；不提供游戏单步试探。命令顺序调整、移除或清空仅作用于未运行草稿。

自由排序时，点击形状添加或替换本轮的选择指令，并显示出生形状，运行时才分配实际实例。固定顺序时，当前方块由队列给出，不能改序。实例编号仅供内部身份与用量校验。

## 碰撞与悬空

| 情况 | 行为 |
| --- | --- |
| 左右移动的任一格受阻 | 整条指令无效，不产生部分位移；接地时终止流程，否则继续下一步 |
| 旋转找不到合法位置 | 本步无效，继续下一步 |
| 下移途中实际受阻 | 停在最后合法位置，终止尾部步骤并固定 |
| 下移刚好接地 | 继续执行后续步骤；横移离开障碍后可继续下移 |
| 明确落地指令 | 降至最低合法位置，固定并结束本轮 |
| 正常执行到末尾 | 在当前坐标固定，即使悬空，随后换块 |
| 自动下落接地 | 等待下一次自动下落；若仍受阻则终止剩余流程并固定 |
| 暂停 | 不固定、不清空，恢复后继续游标 |

固定的悬空方块参与之后的碰撞，不再自动坠落。满行消除仍按传统规则令上方整行下移。新方块出生受阻判负，不替玩家调整位置。

下移受阻后固定并换块，是对“停留在那个位置”和“运行结束换下一块”的统一解释；不让被终止的流程又回到即时操作状态。

暂存的底层规则保留，但 PC/手机所有入口暂时隐藏，不进入本轮体验和语音首版。

## 模式与难度

游戏目标为无尽或闯关；下落方式为手动或自动。无尽可设置 0.1–10 格/秒，预设 0.5、1、2、4。编排阶段冻结，自动下降仅发生在运行期间。关卡固定采用手动，不限思考时间。

无尽使用 10×20 棋盘、七袋随机、五块后续显示。闯关采用有限形状、预制棋盘与明确的固定/自由顺序，全部用完且全盘为空才获胜；中途空盘不提前通关。

目前八关包括三个进阶关：七种形状共八块自由拼图、八块固定队列、带初始布局的五种形状共六块。关卡完整定义见 [LEVEL_DESIGN.md](LEVEL_DESIGN.md)。

## 界面与手机

PC 与手机分别使用独立 HTML、样式和视图模块，共用游戏引擎与指令。入口按设备特征选择页面，PC 窄窗口不自动变手机，手机横屏不变 PC。PC 单列左栏显示关卡或后续队列，右侧编排，中间棋盘按可用高度放大。手机使用首屏棋盘、底部操作区、流程编辑抽屉与选关对话框；运行时收起抽屉，暂停入口始终在棋盘上方。

流程区只显示动作文字与执行进度，不提供“该方案可以清空”等预测反馈。形状数量用 ×N，固定队列另行显示出场顺序，不向玩家暴露实例编号。

棋盘格线增强；执行时方块旁显示当前步骤，落地显示快速下降，满行闪烁三次、上方行下移后再结算。背景音乐与游戏音效独立开关，消行越多音量越大，另有过关和失败声音。设置内嵌旋转教学网页，演示七种形状在空场、贴墙和障碍下的真实旋转；独立示例不预演玩家局面。

棋盘位图按实际显示矩形与 DPR 创建，格线在设备像素上对齐，步骤文字使用同一坐标。音频相对上一版增益为 2 倍，移动方向、旋转方向、受阻、接地与悬空固定有独立音效，落地撞击发生在动画到达时；自动下降中间格默认不逐格播放声音。

## 计分与后续范围

当前无尽原型只有普通消行 100/300/500/800 × 等级，以及玩家软降每格 1、硬降每格 2 分；自然重力不计距离分。闯关以全部使用和全清判定，不以分数替代目标。

真实语音、完整 SRS、T-Spin/连击和正式成绩系统仍未实现。语音未启用时不请求麦克风权限。本轮不增加账户、联机、公开发布或地图编辑器。




## 道具体验（2026-10-24 已确认）

无尽、常规、舒航共用特殊方块玩法。道具放在棋盘既有侧栏，不新增整行占据棋盘高度；按钮显示中文名称和剩余数量，移动端至少 44px 触摸高度。点击立即消耗并替换当前块，不弹瞄准窗口、不保存旧块。通过原左右、下移、落地按钮操作，单格无需旋转。穿墙单格闪烁；炸弹显示弹体和闪烁引线，碰撞后有九宫格闪光、扩散冲击圈、碎片和独立合成爆炸音效。

开局各一个；每 1000 分交替补充一个，最多存四个，侧栏提示距下次奖励所需分数或排队奖励数。重开/切换模式创建新局，库存与奖励阈值重置；舒航跨层保留库存，替换后的候选仍占一个名额。帮助解释立即扣减、替换和整批执行规则。完整碰撞、消行、奖励与失败规则见 COMMAND_SET.md。


## 连点防误选及落地后填洞（2026-10-24）

游戏操作区和按钮文字禁用文本选择及 WebKit 文字长按菜单，防止快速点击、长按方向按钮时弹出复制菜单；输入和可编辑内容保留编辑能力。未拦截全局触摸、点击或滚动。

落地按钮支持长按半秒在“落地并提交”和“落地”间切换，并有颜色、文字与短暂提示反馈。只落地后允许先贴近堆积，再横移进入上方被遮住的空隙，最后提交。默认动作保持落地并提交。常规模式只落地会等待显式提交，避免重力立即锁定；无尽和解谜可以分多次流程调整；舒航可在同一候选中编排落地后横移，保持整批执行。
