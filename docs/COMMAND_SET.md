# 统一指令集 · 流程专用

日期：2026-10-20。两种游戏模式均只编排，不提供立即操作。

## 方块指令

| ID | 按钮 | 参数 | 执行效果 |
| --- | --- | --- | --- |
| MOVE_LEFT | 左移 | cells：1–9，默认 1 | 任一格受阻则整条不移动；接地时受阻则终止流程并固定，否则继续 |
| MOVE_RIGHT | 右移 | cells：1–9，默认 1 | 同上 |
| MOVE_DOWN | 下移 | cells：1–20，默认 1 | 逐格下降；刚好接地可继续执行，下一格实际受阻时终止流程并固定 |
| ROTATE_CW | 顺转 90° | 无 | 旋转失败跳过，不终止 |
| ROTATE_CCW | 逆转 90° | 无 | 同上 |
| HARD_DROP | 落地并提交 | 无 | 点击后追加到草稿并自动运行全部步骤；快速下落动画后提交并结束流程 |
| SELECT_PIECE | 选择形状 | type：I/O/T/J/L/S/Z | 仅自由排序关卡；运行时分配未使用实例 |
| HOLD | 暂存 / 交换 | 无 | 底层保留，当前两端入口隐藏；仅无尽，交换后结束流程，不固定新换入方块 |

UI 共用格数选择器提供 1–9，添加一次操作后恢复默认 1 格；向下更远可编排多条或使用落地指令。命中障碍时不穿墙，也不把超范围数字静默截断。

PC/手机操作按钮顺序统一为：左移、右移、下移、顺转、逆转、落地；与指令目录的内部存储顺序分离。语音仍未接入，也不提供暂存语法入口。

选择指令加入本轮草稿，并在出生位置显示该形状。再次点击其他形状替换已有选择指令和显示，不占用库存，不执行移动或旋转；当前方块显示按现状直接下落的影子。暂停按钮左侧的旋转预览入口按逆时针、顺时针的顺序打开双按钮；方向按钮反复点击可在临时副本上连续旋转，并按真实碰撞规则横向试移，棋盘直接显示副本而不显示旋转虚影。鼠标移出双按钮区域、关闭预览或开始流程时恢复原状；手机点击区域外或再次点击入口可关闭。预览不改变游戏数据或草稿，不预演完整流程。实例在运行时才分配。固定顺序库存逐块按出场次序显示，点击给出规则提示，不能改选。

## 流程与管理

- 添加、移除和上移步骤只修改草稿，一轮最多 60 步。
- 运行前仅检查指令 ID、参数类型及范围，不模拟棋盘，不预测成败。
- 首条在运行后约 450 毫秒执行；后续步骤至少相隔 450 毫秒，当前动画未完成时等待。自动下落仅在运行期间发生。
- 明确落地展示约 260 毫秒快速下降；满行闪烁三次（480 毫秒）后，上方行用 180 毫秒下移，最后统一结算、清空流程及换块。暂停保留当前动画进度，重开或切局丢弃旧动画。
- 当前执行步骤在方块旁显示，右侧列表同时保留；不把下一步误标成正在执行步骤。
- 一轮只操作一块，落地提交、下移或自动下落实际受阻，以及接地时横移受阻会截断尾部步骤，不续接给下一块。刚好接地可横移；横移后下方若有空间，可再次下移，按新位置判断下一次碰撞。
- 自然结束在当前坐标固定，不要求先落到底部。
- 无尽与闯关均在正常或受阻结束时清空草稿；下一块使用新流程。
- 暂停保留流程和游标，继续不重放已执行步骤。暂停中不允许改写运行中的流程。
- 运行中不接受新的方块指令，设置只能在本轮完成后修改。
- 重开恢复该关初始棋盘、库存、固定队列和计数；活跃局重开有确认。
- 模式/关卡切换开始对应新局；帮助和语音说明在运行期间打开时先暂停。

没有 SET_INPUT_MODE、STEP_PLAN 或公开的预演入口。按钮、后续语音只负责追加方块指令，运行器是唯一执行入口。

“落地并提交”按钮负责追加并启动同一运行器。设置内的旋转演示使用独立示例棋盘及真实旋转函数，不能读写或预测当前游戏局面。背景音乐和游戏音效独立设置并在本地保存，结果音只在最终结算时播放一次。

## 引擎边界

startFlow 保存指令副本和当前方块身份；stepFlow 依序执行；endFlow 固定所属方块、结算、换块，并清空运行状态。严禁本轮结束时把刚出生的新方块再次固定。

库存按形状聚合，内部仍以唯一实例标记用过的方块。×N 是未提交的剩余总数，包含当前待用方块；仅编排不扣减，提交后减少。

后续语音将中英文短句映射为相同 ID 与参数，最终转写才追加，重复回调按识别结果身份去重；不靠大模型猜动作。目前只有语音说明页，没有实际识别。


## 2026-10-24 舒航整层编排

`startBatch` 接收 `{pieceId, steps}` 数组，必须包含本层全部独立实例且不重复。每块只允许 MOVE_LEFT / MOVE_RIGHT / ROTATE_CW / ROTATE_CCW，移动格数仍为 1–9，每块最多 59 步；空步骤合法。校验失败不改变任何游戏状态。

接收后复制并锁定整层方案。逐个在实际出生位置生成实例，将系统 HARD_DROP 附加到每块步骤末尾，复用 startFlow / dispatch / stepFlow 的碰撞、旋转与结算，通过 stepBatch 串联。单块完成不生成普通无尽队列；最后一块完成后才增加通过层数、保留棋盘和分数并生成新候选。出生溢出终止整批，不消耗尚未执行的候选。pauseFlow / resumeFlow 仅冻结/恢复进度。

规划时无 active 实例，不执行 advance；UI 仅对当前选中候选显示出生位置和初始方向，不展示落点或草稿旋转结果；不能通过普通流程入口跳过整层校验。舒航模式关闭单块撤回。



## 特殊道具方块（2026-10-24）

无尽、常规和舒航提供穿墙单格与炸弹；解谜不提供。点击道具是立即替换操作，不加入草稿：立即扣库存、取消原块，在顶部生成单格道具，同时清除该块旧草稿与撤回历史。舒航替换选中候选的类型，保留 ID 和本层候选数量，仍需整批提交。移除安排、切换道具或清空草稿不退道具。运行和动画期间不可替换。

普通七形随机袋与解谜 SELECT_PIECE 的允许类型不变。特殊类型仅由已消费道具产生。每局各送一件，每累计 1000 分交替发穿墙单格、炸弹，合计最多四件，满额奖励排队；腾出空间后自动补发。撤回消行时分数、阈值与奖励一起恢复，不能重复领取。

- 穿墙单格：矩阵 1×1，不能旋转，闪烁显示。左右及下移可以穿过固定格，仍不得越界；越界横移整步无效。HARD_DROP 定位整列最低空格，包含被上层方块封住的洞。自然结束可在空格悬空固定；结束在固定格内部时先向下找空格，再向上找空格；整列无空格则失败，绝不覆盖已有格。正常满行继续按统一积分与下移规则结算。
- 炸弹：矩阵 1×1，不能旋转，沿用下落与逐格移动。向左、右、下尝试进入已有格或越界就引爆；多格横移走到碰撞前最后合法格才爆炸。HARD_DROP 到接触点引爆。流程自然结束时尚未碰撞则自动落地引爆。爆炸范围为自身为中心 3×3，边缘裁剪，只删除范围内已有格，不留炸弹实体、不额外计分、不让范围外方块下坠。引爆结束当前块的流程，尾部动作不再执行；舒航继续下一候选。

两种道具在常规模式继续自动下落，在无尽自动模式仅流程执行期间自动下落，在舒航仍按整批执行的自动落地规则。暂停冻结执行及爆炸动画进度。道具奖励与等级提升共用实际消行得分，不为爆炸删除量加分。


## 落地后调整与提交（2026-10-24）

同一落地按钮默认 HARD_DROP（落地并提交）；长按约半秒切换 LAND（只落地），长按本身不添加或执行指令，移动或取消手势取消长按。按钮显示当前模式，可通过 Shift+Enter 同样切换。

LAND 快速降至当前列的合法落点但不写入棋盘、不扣方块库存、不消行计分，也不更换方块。它打开当前块的待提交状态：后续左右、下移与旋转仍可调整；普通流程结束或碰到边界均不自动固定，自动下落及锁定也等待。HARD_DROP 始终落地并提交；SUBMIT_PIECE 在当前位置提交。提交、重开、换块或使用道具替换时清理等待状态。普通未使用 LAND 的流程仍沿用自然结束即固定规则。

无尽/解谜点击 LAND 只在草稿中加入一个落地步骤，和添加移动步骤一样，点击时不运行流程也不改变棋盘。玩家可以继续在 LAND 后编排横移等动作；显式运行流程或点击 HARD_DROP 运行并提交后，才按顺序执行全部步骤。单独运行至 LAND 后保留方块。玩家可继续编排动作并点“运行调整步骤”，调整结束后无草稿时原运行按钮变为“提交当前方块”；也可长按切回 HARD_DROP 一次落地并提交。多次调整共用首次执行前的整轮快照，撤回恢复完整原始回合。

常规模式 LAND 后仍可即时左右、下移及旋转，重力锁定等待，出现“提交当前方块”。提交后恢复原速度自动下落；暂停/继续保持待提交状态。舒航允许候选步骤包含 LAND 和 HARD_DROP，但不会提前执行单个候选；完整方案提交后才能依次执行，每块末尾仍补统一 HARD_DROP，显式提前 HARD_DROP 之后的尾部不再执行。

穿墙单格 LAND 后也可继续调整；整列满时照常失败。炸弹 LAND 到接触点仍立即引爆，不能延迟或撤销碰撞。
