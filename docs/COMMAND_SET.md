# 统一指令集 · 流程专用

日期：2026-10-20。两种游戏模式均只编排，不提供立即操作。

## 方块指令

| ID | 按钮 | 参数 | 执行效果 |
| --- | --- | --- | --- |
| MOVE_LEFT | 左移 | cells：1–9，默认 1 | 任一格受阻则整条不移动；接地时受阻则终止流程并固定，否则继续 |
| MOVE_RIGHT | 右移 | cells：1–9，默认 1 | 同上 |
| MOVE_DOWN | 下移 | cells：1–20，默认 1 | 逐格下降；刚好接地可继续执行，下一格实际受阻时终止流程并固定 |
| ROTATE_CW | 顺转 90° | 无 | 旋转失败跳过，不终止 |
| ROTATE_CCW | 逆转 90° | 无 | 同上 |
| HARD_DROP | 落地并提交 | 无 | 点击后追加到草稿并自动运行全部步骤；快速下落动画后提交并结束流程 |
| SELECT_PIECE | 选择形状 | type：I/O/T/J/L/S/Z | 仅自由排序关卡；运行时分配未使用实例 |
| HOLD | 暂存 / 交换 | 无 | 底层保留，当前两端入口隐藏；仅无尽，交换后结束流程，不固定新换入方块 |

UI 共用格数选择器提供 1–9，添加一次操作后恢复默认 1 格；向下更远可编排多条或使用落地指令。命中障碍时不穿墙，也不把超范围数字静默截断。

PC/手机操作按钮顺序统一为：左移、右移、下移、顺转、逆转、落地；与指令目录的内部存储顺序分离。语音仍未接入，也不提供暂存语法入口。

选择指令加入本轮草稿，并在出生位置显示该形状。再次点击其他形状替换已有选择指令和显示，不占用库存，不执行移动或旋转；当前方块显示按现状直接下落的影子。暂停按钮左侧的旋转预览入口按逆时针、顺时针的顺序打开双按钮；方向按钮反复点击可在临时副本上连续旋转，并按真实碰撞规则横向试移，棋盘直接显示副本而不显示旋转虚影。鼠标移出双按钮区域、关闭预览或开始流程时恢复原状；手机点击区域外或再次点击入口可关闭。预览不改变游戏数据或草稿，不预演完整流程。实例在运行时才分配。固定顺序库存逐块按出场次序显示，点击给出规则提示，不能改选。

## 流程与管理

- 添加、移除和上移步骤只修改草稿，一轮最多 60 步。
- 运行前仅检查指令 ID、参数类型及范围，不模拟棋盘，不预测成败。
- 首条在运行后约 450 毫秒执行；后续步骤至少相隔 450 毫秒，当前动画未完成时等待。自动下落仅在运行期间发生。
- 明确落地展示约 260 毫秒快速下降；满行闪烁三次（480 毫秒）后，上方行用 180 毫秒下移，最后统一结算、清空流程及换块。暂停保留当前动画进度，重开或切局丢弃旧动画。
- 当前执行步骤在方块旁显示，右侧列表同时保留；不把下一步误标成正在执行步骤。
- 一轮只操作一块，落地提交、下移或自动下落实际受阻，以及接地时横移受阻会截断尾部步骤，不续接给下一块。刚好接地可横移；横移后下方若有空间，可再次下移，按新位置判断下一次碰撞。
- 自然结束在当前坐标固定，不要求先落到底部。
- 无尽与闯关均在正常或受阻结束时清空草稿；下一块使用新流程。
- 暂停保留流程和游标，继续不重放已执行步骤。暂停中不允许改写运行中的流程。
- 运行中不接受新的方块指令，设置只能在本轮完成后修改。
- 重开恢复该关初始棋盘、库存、固定队列和计数；活跃局重开有确认。
- 模式/关卡切换开始对应新局；帮助和语音说明在运行期间打开时先暂停。

没有 SET_INPUT_MODE、STEP_PLAN 或公开的预演入口。按钮、后续语音只负责追加方块指令，运行器是唯一执行入口。

“落地并提交”按钮负责追加并启动同一运行器。设置内的旋转演示使用独立示例棋盘及真实旋转函数，不能读写或预测当前游戏局面。背景音乐和游戏音效独立设置并在本地保存，结果音只在最终结算时播放一次。

## 引擎边界

startFlow 保存指令副本和当前方块身份；stepFlow 依序执行；endFlow 固定所属方块、结算、换块，并清空运行状态。严禁本轮结束时把刚出生的新方块再次固定。

库存按形状聚合，内部仍以唯一实例标记用过的方块。×N 是未提交的剩余总数，包含当前待用方块；仅编排不扣减，提交后减少。

后续语音将中英文短句映射为相同 ID 与参数，最终转写才追加，重复回调按识别结果身份去重；不靠大模型猜动作。目前只有语音说明页，没有实际识别。
