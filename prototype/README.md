# VoxArcade HTML 原型 · 流程专用版

本地 HTML/CSS/JavaScript，无构建、无需安装依赖。

## 启动

在 D:\MyProject\VoxArcade 执行：

```powershell
node prototype/serve.mjs
```

电脑访问 http://localhost:4173/，手机连接同一局域网后使用电脑 WLAN IPv4 地址和 4173 端口。页面使用 ES 模块，通过 HTTP 服务打开。

## 怎么玩

1. 默认第六关“七形拼图”，也可切第一关入门。共八关，进阶关有六至八块。
2. 自由排序形状旁 ×N 是剩余未用数量，包含当前方块；固定队列逐块按出场顺序展示，点击可查看提示但不可改序。
3. 点击形状后立即显示出生形状，影子标出当前方块直接下落的位置。暂停按钮左侧可打开旋转预览；顺逆转按钮会在棋盘上临时转动当前方块，支持连续点击，离开预览区后还原。正式旋转指令仍只加入流程，不提前执行或预演完整流程结果。
4. 点击“落地并提交”自动执行整份草稿；也可点击运行，在流程结束位置固定。左右受阻整步无效，接地时受阻会结束流程；下移刚好接地可横移脱离并继续下移，下一次实际受阻才结束流程。
5. 本轮结束将方块固定在原处，即使悬空，再换块；草稿自动清空。
6. 用完给定方块且全盘为空才通关。暂停可继续游标，不能单步试探。
7. 无尽模式可设置自动下落与速度；编排冻结，只有运行时才下落。
8. 设置可分别开关背景音乐和游戏音效。消行越多声音越大，过关和失败有不同收尾音。
9. 设置内“旋转演示”在当前页面弹出示例，覆盖七形、两个方向及五类场景，关闭后返回原设置和游戏。

同一入口自动加载 PC 或手机视图，窗口缩放或手机横屏不跨端切换。在电脑浏览器按 F12 选手机设备后刷新页面，可按模拟设备重新分流；也可直接访问 `http://localhost:4173/?view=mobile` 强制预览手机版，使用 `?view=desktop` 返回电脑版。PC 棋盘四边显示从 1 开始的行列坐标。选择移动格数并添加一次操作后，格数自动回到 1。PC 使用单列关卡/后续方块栏与右侧流程；手机棋盘与操作按钮保持在首屏内，点击“流程”展开抽屉编辑，运行时收起；点击“选关”打开列表。手机帮助和语音设计说明位于设置中。暂存入口已隐藏，没有键盘游戏快捷键。

网格按实际显示尺寸及 DPR 对齐，避免缩放后细线消失；音频整体增益翻倍，左右、下移、顺逆转、受阻、快速下降、真实接地、悬空固定及结算使用不同事件音。

## 原型范围

已实现：统一指令与流程运行器、碰撞和悬空固定、八关、形状数量、固定/自由排序、暂停重开、无尽暂存、速度配置、本地完成记录。

未实现：真实语音、完整 SRS、T-Spin/背靠背/连击奖励、正式成绩榜。语音按钮只展示说明，不申请麦克风权限。

旋转仍为矩阵旋转和有限横向试移；无顶部隐藏出生区。切换模式或关卡直接新开棋盘，重开有确认。本轮使用新的规则版本记录完成情况，旧原型记录保留但不混用。

## 独立语音验证

访问 http://localhost:4173/voice-check.html，先检测麦克风，再手动加载本地识别模型。首次打开不申请权限、不下载模型；声音不上传、不保存。模型和运行时约 94.2 MB，当前仅中文合成口令通过识别验证，英文存在误识别；手机微信及真人口令待真机验收。此入口不修改游戏流程，也不代表游戏已接入语音。

具体证据、资源开销、命令和未验证范围见 [VOICE_VALIDATION.md](../docs/VOICE_VALIDATION.md)。
